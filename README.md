
# AI Code Challenge · NextLab
## Mission 01 v2.2 — The Brief Is Broken

Навчальне середовище для учнів 11 класу.

У першій місії учень аналізує вимоги до цифрового продукту, формує власну ідею, працює з GitHub Copilot та створює невеликий HTML/CSS-фрагмент за власним дизайном у Figma.

NextLab — навчальна платформа. Власний вебпроєкт учня розміщується окремо в `student-app/`.

## 1. Що потрібно для роботи

- VS Code
- Сучасний браузер
- Python 3
- GitHub Copilot (за наявності доступу)
- Figma або підготовлений макет

Перед використанням ШІ перевірте вікові умови сервісу та правила закладу освіти.

## 2. Запуск NextLab

Відкрийте всю папку проєкту у VS Code:

File → Open Folder

Відкрийте термінал:

Terminal → New Terminal

У корені проєкту запустіть:

```bash
py -m http.server 8000 --bind 127.0.0.1
```

Для macOS або Linux:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

У браузері відкрийте:

http://127.0.0.1:8000/mission-01.html

Не закривайте термінал, поки працюєте з NextLab.

## 3. Запуск учнівського вебпроєкту

Створіть другий термінал у VS Code.

Для Windows:

```bash
py -m http.server 8001 --bind 127.0.0.1 --directory student-app
```

Для macOS або Linux:

```bash
python3 -m http.server 8001 --bind 127.0.0.1 --directory student-app
```

Відкрийте:

http://127.0.0.1:8001/

NextLab і вебпроєкт працюють на різних портах.

- 8000 — навчальна місія.
- 8001 — власний вебпроєкт учня.

Для зупинки сервера використовуйте Ctrl+C у відповідному терміналі.

## 4. Структура проєкту

- `index.html` — стартова сторінка NextLab.
- `mission-01.html` — інтерактивна сторінка першої місії.
- `css/` — стилі NextLab.
- `js/` — JavaScript навчальної платформи.
- `student-app/index.html` — HTML власного проєкту.
- `student-app/css/style.css` — стилі власного проєкту.
- `student-app/assets/` — зображення та інші ресурси.
- `docs/PRODUCT_BRIEF.md` — шаблон Product Brief.
- `docs/DECISIONS.md` — шаблон журналу рішень.

## 5. Робота над Mission 01

Тривалість: 90 хвилин.

Під час місії учень:

1. Аналізує суперечливі вимоги до StudyFlow.
2. Знайомиться з принципами роботи з Copilot.
3. Виявляє суперечності та формулює уточнювальні питання.
4. Визначає власну ідею цифрового продукту.
5. Створює Product Brief і фіксує рішення.
6. Використовує Copilot Plan для планування роботи.
7. Використовує Copilot Agent для реалізації невеликого HTML/CSS-фрагмента.
8. Перевіряє результат у браузері та на вузькому екрані.
9. Виконує самооцінювання і рефлексію.

## 6. Правила роботи з Copilot

Copilot допомагає, але не ухвалює рішення замість учня.

Перед змінами:

- Прочитайте пропозицію агента.
- Перевірте, які файли він хоче змінити.
- Не погоджуйтеся автоматично на всі дії.
- Переконайтеся, що зміни відповідають завданню.

У Mission 01 для реалізації фрагмента дозволено змінювати:

- `student-app/index.html`
- `student-app/css/style.css`

Не дозволяйте агенту змінювати файли самої навчальної платформи NextLab.

Не передавайте ШІ паролі, токени або персональні дані.

## 7. Робота з Figma

Оберіть невеликий фрагмент власного макета.

За потреби експортуйте зображення до:

`student-app/assets/`

Використовуйте зрозумілі назви файлів, наприклад:

`my-hero.png`

Файл `figma-reference.png` є необов'язковим прикладом.

Не потрібно відтворювати весь сайт за одну місію.

## 8. Збереження результатів

NextLab передбачає локальне збереження навчального прогресу в браузері.

Після виконання роботи експортуйте доступні результати у Markdown та JSON.

Збережіть файли експорту у власній папці.

JSON використовується для відновлення прогресу в NextLab.

Не розраховуйте лише на збереження в браузері: очищення даних сайту може призвести до втрати прогресу.

## 9. Самоперевірка

Перед завершенням роботи переконайтеся, що:

- Product Brief заповнено.
- Рішення обґрунтовано.
- HTML-фрагмент відображається в браузері.
- CSS застосовується.
- Результат перевірено на комп'ютері й вузькому екрані.
- Виконано рефлексію.
- Результати експортовано.

Оцінювання Mission 01: шість критеріїв по 0–2 бали, максимум 12 балів.

## 10. Важливо

Mission 01 — початок роботи над власним цифровим продуктом, а не створення готового MVP.

У наступних місіях учень поступово розвиватиме свій проєкт.

Головний принцип NextLab:

**ШІ пропонує. Учень аналізує, вирішує та перевіряє.**

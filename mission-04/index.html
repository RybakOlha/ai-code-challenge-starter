Етап 02 · 12 хв

GitHub Copilot: ASK → PLAN → AGENT

Відкрий стартовий проєкт у VS Code та панель GitHub Copilot Chat. Працюй із трьома режимами послідовно: спочатку розберися в логіці, потім узгодь план, а зміни коду виконуй лише після перевірки плану. Назви режимів і доступність можуть відрізнятися залежно від версії Copilot.

Подія → Зчитування значень → filter() → renderMenu() → Новий список
1 · ASK — зрозумій алгоритм

Вибери режим Ask (якщо доступний). Попроси пояснити принцип без написання готового коду.

Я учень 11 класу. Працюю над JavaScript-фільтрацією меню. Поясни, як поєднати живий пошук за назвою, категорію, максимальну ціну та прапорець «Лише вегетаріанські» в одному Array.filter(). Не пиши готової функції. Поясни роль input, change, trim(), includes(), логічного && та renderMenu(). Постав два запитання для перевірки розуміння.

2 · PLAN — перевір план змін

Вибери Plan, якщо він доступний. Передай Copilot структуру файлів і попроси план без редагування. Перевір, чи всі чотири фільтри працюватимуть одночасно.

Проаналізуй index.html і js/app.js відкритого навчального проєкту. Склади покроковий план реалізації чотирьох комбінованих фільтрів: назва, категорія, максимальна ціна, лише вегетаріанські. Не змінюй файли та не генеруй готове рішення. Вкажи, які елементи DOM читати, які функції змінити, як обробити порожній результат, скидання і як перевірити кожну умову. Збережи асинхронне завантаження меню.

3 · AGENT — контрольована допомога з кодом

Режим Agent може змінювати файли. Спочатку самостійно реалізуй частину логіки на етапах 03–04. Потім попроси перевірити конкретний фрагмент або запропонувати мінімальне виправлення. Перед прийняттям змін переглянь diff.

Перевір лише js/app.js у моєму проєкті. Мета — чотири одночасні фільтри. Спочатку поясни знайдену проблему і запропонуй мінімальну зміну. Не змінюй HTML, CSS, дизайн чи інші файли. Не застосовуй зміни без мого підтвердження. Після виправлення запропонуй тести для всіх фільтрів та їх комбінацій.

Етап 03 · 20 хв

Програмуємо пошук і категорії

  1. Відкрий starter/js/app.js та знайди TODO.
  2. Прочитай значення текстового поля, прибери пробіли й урахуй регістр.
  3. Застосуй includes() до назви страви.
  4. Додай перевірку категорії; all означає «усі».
  5. Переконайся, що зміна одного фільтра не скидає інший.
Підказка · Не готова відповідь

Для пошуку використовуй trim() та toLocaleLowerCase('uk-UA'). Умови в filter() можна об'єднувати оператором &&.

Промпт · Діагностика

Перевір мій фрагмент JavaScript для живого пошуку й категорії. Спочатку знайди можливі логічні помилки, поясни причину кожної та запропонуй мінімальне виправлення. Не переписуй увесь файл.

Етап 04 · 25 хв

Додаємо ціну та вегетаріанський фільтр

  1. Прочитай максимальну ціну з select.
  2. Перетвори її на число лише тоді, коли обрано конкретний ліміт.
  3. Порівняй item.price із лімітом.
  4. Прочитай стан checkbox.checked.
  5. Додай перевірку поля item.vegetarian.
  6. Об'єднай усі чотири умови в одній функції та реалізуй скидання.
Пастка: рядок "50" і число 50 — різні типи даних. Значення all не можна перетворювати на звичайну ціну.
Промпт · Допомога без підміни мислення

У мене вже працюють пошук і категорія. Допоможи додати максимальну ціну та vegetarianOnly. Поясни різницю між значенням select і checkbox.checked. Спершу дай план змін, потім перевір мій код, а не створюй новий проєкт.

Асинхронність у дії

Коротка теорія

Promise представляє майбутній результат операції. async дозволяє використовувати await, який призупиняє виконання поточної асинхронної функції до завершення Promise. try/catch допомагає опрацювати помилку, а finally виконує завершальні дії, наприклад знімає блокування кнопки.

function mockReply(message) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (message === '/error') reject(new Error('Збій відповіді'));
      else resolve('Отримано: ' + message);
    }, 1500);
  });
}

async function sendMessage(message) {
  try {
    showStatus('Очікування…');
    const reply = await mockReply(message);
    showStatus(reply);
  } catch (error) {
    showStatus('Помилка: ' + error.message);
  } finally {
    unlockSendButton();
  }
}

Це навчальний приклад: функції showStatus і unlockSendButton — умовні назви; у власній реалізації їх треба визначити.

Мініексперимент

Перед запуском спрогнозуй, що відбудеться. Потім натисни кнопку й порівняй із результатом.

# Публікація Місії 05 у GitHub Pages

1. Перевірте, що в репозиторії `ai-code-challenge-starter` використовується GitHub Pages із гілки `main` та кореня `/` (або інше фактично налаштоване джерело).
2. У корені репозиторію створіть папку `mission-05` та завантажте **вміст** папки `mission-05` із цього комплекту.
3. Перевірте, що `mission-05/index.html` знаходиться безпосередньо в `mission-05/`, а не в `mission-05/mission-05/`.
4. Перевірте, що `mission-05/css/`, `mission-05/js/`, `mission-05/starter/` завантажені зі збереженням структури.
5. Після публікації відкрийте `https://rybakolha.github.io/ai-code-challenge-starter/mission-05/`.
6. Перевірте переходи між шістьма етапами, посилання на демонстрацію та завантаження ZIP для VS Code.
7. Якщо бачите лише README або список файлів, перевірте URL, шлях до `index.html` і налаштування Pages; не переписуйте HTML навмання.

Файл `README.md`, створений раніше для створення папки, не замінює `index.html`.

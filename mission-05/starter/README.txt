ШКІЛЬНА ЇДАЛЬНЯ 3.0 — ЗАМОВЛЕННЯ БЕЗ ПОМИЛОК

Це стартовий комплект учня, НЕ завершений застосунок.

ЗАПУСК
1. Розпакуйте ZIP у власну папку.
2. Відкрийте папку Mission05_Starter у VS Code.
3. Відкрийте index.html у браузері (або запустіть локальний сервер).
4. Натисніть «Завантажити меню».
5. Перевірте всі 4 фільтри: пошук, категорія, максимальна ціна, вегетаріанські.
6. Натисніть «Замовити» на картці страви.
7. Відкрийте js/order.js та реалізуйте TODO за планом ASK → PLAN → AGENT.

ВАЖЛИВО
- Дані меню і ціни умовні. Для імен використовуйте вигадані приклади.
- Жодні замовлення не надсилаються.
- Функцію isValidQuantity() напишіть САМОСТІЙНО, без генерації коду Copilot.
- У js/app.js фільтри вже працюють. Не переписуйте їх.
- Форма спеціально не підтверджує замовлення, доки ви не завершите TODO.

ПЕРЕВІРКИ
node tests/test_filters.js — 12 автоматичних тестів збереженої логіки фільтрації.
node tests/test_starter.js — структурні перевірки стартового комплекту.

ПІДКАЗКА ДЛЯ УЧНЯ
A: обрана страва; Б: перевірки; В: вартість і підтвердження.
Тестуйте після кожного інкременту.
